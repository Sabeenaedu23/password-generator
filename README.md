# 🔐 Password Generator – Front-End Development Project

## 📌 Project Overview

Password Generator is an interactive web application developed using HTML5, CSS3, and JavaScript. It allows users to generate random passwords based on their preferred settings.

The project focuses on JavaScript logic, user interaction, and creating a simple and user-friendly interface.

## ✨ Key Features

- Generate random passwords
- Customizable password length
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include special characters
- Copy generated passwords to clipboard
- Responsive user interface

## 🛠️ Technologies Used

- HTML5 – Application structure
- CSS3 – Styling and responsive design
- JavaScript – Password generation logic and functionality

## 📱 Responsive Design

Designed to provide a smooth user experience across:
- Desktop
- Laptop
- Tablet
- Mobile devices
